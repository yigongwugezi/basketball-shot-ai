Frame notes

Workflow: inspect the image, optionally press B to seed a draft, drag/click joints, set visibility, then check Human-reviewed. Prediction overlay and GT are separate data layers.

Keys: ←/→ frames · B seed · P prediction · R reset selected joint · C clear selected joint · V cycle visibility · [/] zoom. Wheel also zooms. Autosaves to this browser; Save JSON writes the human annotation file.

White cross = model prediction. Cyan = left GT. Orange = right GT. not_labelable stores no coordinates and is excluded from accuracy.
